Dialbot MCP

Política de privacidad

Actualizada: 8 de octubre de 2026

Dialbot MCP es una extensión de Chrome y un puente MCP local para Windows. Esta política describe la información que el software puede manejar y quién puede recibirla.

Información que se procesa

Cuando el usuario o su cliente MCP invoca una herramienta, Dialbot puede acceder a las pestañas abiertas y procesar sus direcciones y títulos, el texto visible, enlaces, capturas de pantalla y el contenido que se introduzca. Las herramientas de selección de archivos reciben rutas locales y hacen que Chrome seleccione los archivos indicados. El contenido binario de esos archivos no se transporta a través del servidor MCP.

El puente local usa una credencial generada en el equipo para autenticar la comunicación entre procesos. La función de pegado puede colocar temporalmente el texto solicitado en el portapapeles de Windows.

Cómo se transmite

La comunicación de control se realiza entre la extensión, el proceso local del puente y el cliente MCP configurado por el usuario. Dialbot no opera un servidor remoto de cuentas, no incorpora analítica ni envía telemetría al desarrollador. La política de seguridad de contenido de la extensión bloquea sus propias conexiones de red.

El cliente MCP y el proveedor de IA que el usuario haya elegido pueden recibir el contenido de páginas, capturas, texto o resultados de herramientas y tratarlos según sus propias políticas. Revisa la configuración de privacidad de esos servicios antes de usar Dialbot con información sensible.

Seleccionar un archivo puede iniciar una carga desde Chrome a la página web abierta. Ese envío lo controla el sitio web; no lo realiza Dialbot como servicio. Comprueba el sitio y el archivo antes de seleccionar.

Almacenamiento y control

La credencial del puente y la configuración de instalación se guardan localmente en el directorio `.local` del proyecto y no se incluyen en el repositorio público. Dialbot no conserva una base de datos remota ni mantiene un historial propio de las páginas. El usuario controla las acciones mediante su cliente MCP y puede desconectar la extensión, cerrar el cliente o desinstalar el software.

Servicios de terceros

Estas páginas informativas se alojan en GitHub Pages; el alojamiento puede procesar solicitudes HTTP de acuerdo con la política de privacidad de GitHub. El uso de Chrome, del cliente MCP, del proveedor de IA y de los sitios visitados está sujeto a las políticas de sus respectivos proveedores.

Contacto

Para preguntas o solicitudes de privacidad, abre un issue en GitHub. No publiques allí datos personales, capturas, credenciales ni información sensible.

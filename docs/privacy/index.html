Dialbot MCP

Privacy Policy

Updated: October 8, 2026

Dialbot MCP is a Chrome extension and a local MCP bridge for Windows. This policy describes the information the software may handle and who can receive it.

Information processed

When the user or their MCP client invokes a tool, Dialbot may access open tabs and process their addresses and titles, visible text, links, screenshots and the content that is typed in. The file-selection tools receive local paths and make Chrome select the indicated files. The binary content of those files is not transported through the MCP server.

The local bridge uses a credential generated on the machine to authenticate inter-process communication. The paste feature may temporarily place the requested text on the Windows clipboard.

How it is transmitted

Control communication happens between the extension, the local bridge process and the MCP client configured by the user. Dialbot does not operate a remote account service, includes no analytics and sends no telemetry to the developer. The extension's Content Security Policy blocks its own network connections.

The MCP client and the AI provider the user has chosen may receive page content, screenshots, text or tool results and process them under their own policies. Review the privacy settings of those services before using Dialbot with sensitive information.

Selecting a file may start an upload from Chrome to the open web page. That submission is controlled by the website; Dialbot does not perform it as a service. Check the site and the file before selecting.

Storage and control

The bridge credential and installation configuration are stored locally in the project's `.local` directory and are not included in the public repository. Dialbot keeps no remote database and maintains no history of the pages. The user controls actions through their MCP client and can disconnect the extension, close the client or uninstall the software.

Third-party services

These informational pages are hosted on GitHub Pages; the host may process HTTP requests according to the GitHub Privacy Statement. The use of Chrome, the MCP client, the AI provider and the visited sites is subject to their respective providers' policies.

Contact

For questions or privacy requests, open an issue on GitHub. Do not post personal data, screenshots, credentials or sensitive information there.

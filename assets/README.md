# Assets

- `extension/icons/icon{16,32,48,128}.png` are the icons required by the extension manifest.
- `assets/promo/dialbot-landscape.gif` is a landscape drawn through MCP browser input.
- `assets/promo/dialbot-handwriting.gif` is the `It works!` handwriting demo drawn through MCP browser input.
- `assets/promo/questionnaire-filled.png` is a real browser capture of a completed questionnaire with the agent crosshair visible.

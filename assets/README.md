# Assets

- `extension/icons/icon{16,32,48,128}.png` are the icons required by the extension manifest.
- `assets/promo/questionnaire-filled.gif` is an animated real-browser capture of the agent filling and submitting the questionnaire.
- `assets/promo/github-readme-crosshair.gif` is an animated real-browser capture of the agent reviewing this GitHub README with the agent crosshair visible.
- `assets/promo/dialbot-landscape.gif` is a landscape drawn through MCP browser input.
- `assets/promo/dialbot-handwriting.gif` is the `It works!` handwriting demo drawn through MCP browser input.
- The matching `.png` files are the final still frames used as source captures.
